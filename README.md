# Diabetes_Predict
An AiMl model for diabetes stage prediction ,meal planner and also medicine recommendation made with numpy, pandas,scifit and streamlit
## Acknowledgements

This project was developed collaboratively as part of an academic group project.

We worked together on the design, development, and implementation of the Diabetes Predictor application using Python, Machine Learning, and Streamlit.
